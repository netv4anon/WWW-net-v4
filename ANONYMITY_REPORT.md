# Anonymous distribution inspection

This report concerns the files supplied for anonymous review. It is separate
from private submission administration and does not identify the authors.

- Filenames, readable text, nested archive members, NumPy string metadata,
  inspectable checkpoint metadata and all included PDFs were inspected.
- No identifying local account name or personal home-directory path was found.
- No author email, author affiliation, personal repository URL, credential or
  manuscript registration identifier is intentionally supplied.
- The technical evidence PDF has an empty Author metadata field and an
  anonymous visible author field. Scientific figure PDFs also have empty Author
  metadata. The main manuscript and its typesetting files are excluded.
- Third-party publications, software copyright notices and the data publisher's
  public contact address remain because they document upstream sources.
- Editorial review notes and obsolete scope-planning documents were excluded.
  All experimental arrays, targets, weights, forecasts and adverse results remain.
- The release ZIP has a neutral root name, fixed outer member timestamps and no
  ZIP comments, personal directory prefix or operating-system account metadata.

No personal hosting URL is inserted. Hosting-page ownership, access permissions
and download behavior must also preserve anonymity when this artifact is made
available online. Inspection of local files cannot certify an external host's
behavior or prevent identification through already public research.
