# 使用示例一：总分更好是否说明响应有效？

读者是一位已有 12→12 交通预测模型的研究者，希望判断加入受控事件操作之后，较低误差是否说明历史信息被有效利用。普通做法只比较事件臂与背景臂各自的误差，输入和目标同时改变，无法单独回答响应问题。

本例直接读取 mixed 训练的三个已保存 STID 预测，不重新拟合、不重新预测。它们在完全相同的 256 个构造上下文上评分。均值：背景 MAE 9.035021，完整操作 MAE 8.472192，表面改善 0.562829。

固定完整操作的目标后，背景历史预测 MAE 8.364074，完整历史预测 MAE 8.472192；响应收益 A=-0.108118，因此改变历史在此固定目标上增加误差。三个种子均为负。

|训练版本/种子|目标法则|背景 MAE|完整操作 MAE|固定目标响应 A|
|---|---|---:|---:|---:|
|Mixed / 1|legacy|9.129352|8.552075|-0.154979|
|Mixed / 1|residual_recovery|9.129352|9.250282|-0.084139|
|Mixed / 2|legacy|8.979214|8.375616|-0.126504|
|Mixed / 2|residual_recovery|8.979214|9.077888|-0.090586|
|Mixed / 3|legacy|8.996497|8.488884|-0.042871|
|Mixed / 3|residual_recovery|8.996497|9.192940|+0.005510|

仅换恢复目标、保持所有历史与预测不动后，完整操作 MAE 变为 9.173703，对背景的原低误差比较消失。响应均值 A=-0.056405，但有一个种子转为略正，不能声称目标改变后三种子都保持负响应。完整输出同时保留另外八个配置；Mixed Ridge 在原法则下是正响应，诊断并不强迫所有模型得到负结论。

读者现在可以作出更精确的论文判断：该模型在原构造下误差较低，但这项低误差不能解释为历史响应改善；还必须声明目标法则。资源提供历史/目标分离、按 ID 对齐的预测、交叉损失和逐上下文输出，使这项判断可复核。它不证明模型识别真实事故，也不提供事故因果效应或新的损失分解理论。

复用流程：在统一资源目录运行 `python resource.py replay netv4 --out <全新目录>` 可重放全部十一组既有预测与两种恢复目标。读者自己的预测用 `python resource.py score netv4 --predictions <NPZ> --out <全新目录>`；必须提供 1024 个不含臂语义的 sample_id 和对应 12 步预测，历史包含同一上下文的 B/P/R/F 四臂。接口可直接调用用户仅历史预测函数。预测文件哈希与所有交叉结果保留，不能只截取一行均值。

先前的中心示例重放位于 `example_runs/response`。原 256 个上下文有开发暴露和构造依赖；它们不增加独立现场样本。三个种子不是三个独立事故研究。本次文字修订没有重复拟合、推理或科学评分。

## 联合输入延伸：整体响应有利，其他输入是否有用？

中心任务只接收中心历史。需要跨序列计算的读者应使用单独标识的 MV 接口：68,544 条完整 `[N,12,9]` 历史，包括每场景的 B/P/R/F/C/N 六视图。中心和副本固定在事件历史时，C 使用其他序列的背景历史，F 使用其他序列的事件历史；两者评分目标完全相同。

固定 Graph WaveNet 的已有六个主配置，在全部主种子和两种目标下都保留“整体响应有利、其他条件响应有害”。以下为三种子损失均值，不能当成平均预测的评分：

| 训练版本 / 目标 | 总响应 A | L_CF | L_FF | 条件误差增加 |
|---|---:|---:|---:|---:|
| Generated / legacy | +1.0608 | 14.6978 | 15.1102 | 2.81% |
| Generated / residual | +1.0927 | 15.3663 | 15.9103 | 3.54% |
| Mixed / legacy | +1.4422 | 14.0995 | 14.4594 | 2.55% |
| Mixed / residual | +1.5156 | 14.9408 | 15.3354 | 2.64% |

读者可保留“在这组场景中，全部事件历史相对背景历史有帮助”，同时收窄“其他序列帮助预测”的解释。真实预测变化与梯度检查确认该模型使用了其他槽；结果不能解释成未接入其他序列的模型天然零响应。102 个轮廓中有帮助的组仍报告，时序总体与跨起点组的相反判断也保留。

准确率要同时读：Graph WaveNet 原 Generated 测试优于 STID，Mixed 测试更差；MV 跨起点 legacy 准确率在两版本下都差于 STID。这些结果是资源用途证据，不能改写成算法普遍胜出。其他槽由数值轮廓相似度选择，不提供实测道路干预或物理传播结论。

从资源根目录执行一个已有神经配置的评分：

```text
python -B resource.py score netv4_mv --predictions components/netv4_gwn/runs/working__GraphWaveNet_seed1/mv_predictions.npz --out ../gwn_example_scores
```

在 `scores/responses.csv` 选择 `scope=cutoff_spanning`、`phase=all_points` 与目标法则，读取 A、L_CF、L_FF 和 `neighbor_given_center`；并联读准确率、全部时序和轮廓组。该命令是一个种子的技术重放，四行均值来自 `components/netv4_gwn/evaluation/primary_seed_loss_means.csv`。适配器、历史输入和所有六个主配置见组件 README；换成自己的固定预测仍用相同评分入口。
