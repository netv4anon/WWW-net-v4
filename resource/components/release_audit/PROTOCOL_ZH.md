# 公开切分的历史查表诊断：执行前固定

2026-10-07。对象仅为已下载的 IGSTGNN data4igstgnn 版本 1 Contra_Costa。采用作者脚本的 3909/837/839 行切分，不更换地区、日期、排列、容差或样本。此前结构审计已查看所有目标并发现 93 个测试行的历史与目标共同重复，因此这是已暴露开发数据上的机制诊断，不是盲测或对已有论文性能的复现。

## 问题及固定规则

仅凭预测时可见的完整 12×496×3 历史张量，能否检索训练记录并利用其未来交通值？检索键包含原始 float32 流量及日内/星期通道；不使用查询的目标、事件描述、位置或最终持续时间。匹配要求完整原始字节相同，先 SHA256 筛查，再核对字节。

训练库仅含行 0…3908。固定两个预测器：(1) LastValue，将最后历史交通值重复 12 格；(2) ExactHistory，当历史键在训练库存在时，使用所有对应训练记录的目标流量均值，否则使用 LastValue。多候选按行号升序取算术均值，不以查询目标决定候选。不调参、不训练神经模型。必须报告训练键冲突数（同历史不同目标）、命中率和全部候选，不仅展示有利例子。

实现必须先读取全部查询历史和训练目标并落盘预测，记录输出哈希，然后才读取验证/测试目标评分。先前审计的目标暴露如实保留。这一程序隔离不把开发暴露变成独立测试。

## 评分与诊断

用作者 mean/std 反变换到流量单位，float64 运算，不作额外截断或零值屏蔽；每行全部 12×496 目标点等权。报告验证、测试的全体/查表命中/未命中 MAE、RMSE、LastValue 与 ExactHistory 差值及相对差；空集合记 null。保存每行损失和预测，不做事件因果或统计显著性推断。

另报告测试/验证中“任何全路网单格目标与训练目标相同”和“不相同”两个描述性分层，数值含交通与日历三通道；不得把这种使用目标定义的分层叫可部署选择、独立测试、原始事件身份恢复或修复后的时间划分。分层目的是定位分数变化，不能把分层间难度差当作泄漏效应。

独立复核重新从原始文件解码 x/y，直接以完整字节建训练键（不用主程序候选哈希表），重新检索并逐值复核预测、全部候选、每行与聚合分数。验证训练库仅来自训练行、原始文件未变、查表未访问查询目标。预测均值构建算非参数索引建设，不计优化拟合；账本单独记录两种配置、1676 个查询/配置、两次独立预测重放。

## 结论边界

这是普通记忆查表对照，不是新算法。正结果只证明当前公开切分允许这个预测规则获益；不能推断 IGSTGNN 神经模型实际利用了多少重复、论文历史实验的成绩有多大偏差、未命中行没有其他重叠、或源时间身份已经恢复。负结果也必须完整保留。
