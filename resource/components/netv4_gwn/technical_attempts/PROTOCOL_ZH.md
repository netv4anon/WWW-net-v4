# 一次联合神经模型资源用途验证：执行前协议

2026-10-09。用户授权填补完整输入示例主要来自联合Ridge、STID没有跨序列聚合的证据缺口。本项为一项有限研究，采用一个既有公开架构Graph WaveNet。不调整NET-V4、MV时序、数值轮廓、目标或划分，不启动模型搜索。此前论证修订候选及独立v0.7保留。

## 模型及数据身份

官方Graph WaveNet代码使用本地已获取commit 6b162e80c59a1d494809252eca055cff93dc66b1，MIT许可。将原三处二维核Conv1d声明机械替换为Conv2d，以兼容当前PyTorch；单输入流量通道、12输出步，官方宽度32/32/256/512、4 blocks×2 layers、dropout 0.3。保留自适应邻接和二阶图卷积，不输入实测图、日历或事件参数。

九个位置为局部数值槽，含中心副本。学习到的连接描述这些位置的模型交互，不是实测道路关系或新图算法。训练按原NET-V4两个快照分别进行，全部种子1、2、3，共六个拟合。它们属于一个架构的一项研究，不是六种方法或六个独立数据集。

每个拟合用原训练/验证索引，训练历史全局均值/标准差归一化，九槽L1监督，Adam lr=0.001、weight_decay=0.0001、batch=256、梯度截断5，固定30 epochs。在每个epoch用验证中心MAE选择检查点，预测反归一化并截断到非负。原测试目标从拟合接口排除；MV目标不用于训练、超参或检查点选择。为用途示例而接入标准架构，不作为严格架构消融或SOTA宣称。

## 固定问题及报告

主要问题：在既有2,856个cutoff-spanning MV条件场景中，改变其他七条历史的收益，是否与改变所有历史的总收益一致？固定F目标，报告L_BF−L_FF总响应A、L_CF−L_FF条件其他响应、L_BF−L_NF背景中心条件响应，以及L_BB/L_CF/L_FF和B/P/R/F准确率。legacy/residual两目标、两个训练快照、全部三种子均报告。种子摘要平均损失，不能把平均预测代替平均损失。

继承Ridge四行反例为对照，不预设神经模型也应有害。若A>0而条件其他响应<0，说明整体收益不能替代该输入组判断；若其他响应有利，明确保留这一正结果，不能说资源使所有联合模型表现有害。

次要、预先指定检查：全部场景和四种时序的响应与准确率；102个轮廓组；原快照测试中心MAE；与现有冻结参考模型的准确率和响应并列。不得只展示发生反转的种子或子群。所有实际量级和相对误差变化均报告，符号不等于重要性或统计显著性。

## 分阶段封印与核对

模型训练完成后先固定权重、归一化、epoch日志和文件哈希。推理只读取MV历史和传输ID，保存所有68,544行、12步中心预测；六份预测一起封印后才解码MV评价目标、运行原评分器。旧开发暴露仍在，文件阶段分离不是安全沙箱或独立盲测。

验证跨序列参与：实际C/F及B/N预测差异和输入梯度；中心历史不变而其他历史改变时，预测若没有可核查变化，则不能宣称本次提供了有效联合输入示例。未来起始组完整历史相同，响应必须在1e-3容差内为0。另一次直接数组损失核对评分器主行；CPU输入适配器与封印预测核对，允许1e-3数值容差。

不设“WWW达到4分”的数值门槛。用途是否更有分量，按神经模型是否真实使用完整输入、评价是否改变具体解释、效应量级与种子/目标条件稳定性判断。科学结果和内部评分分别记录；即使全部技术检查通过也不能自动升级评分。
