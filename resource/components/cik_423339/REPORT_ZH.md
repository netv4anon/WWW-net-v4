# WWW 资源定位与外部构造诊断

本轮取得了能改变下一步安排的新证据：目标构造诊断在另一份公开交通任务实现上产生了可复核用途，不再只有 NET-V4 自身的构造对照。同时，WWW 2027 当前官方页面已补充资源方向的详细评审标准。本稿仍是资源与评价研究，不是新的预测方法论文；“高概率录用”尚未建立。

## 官方范围的实际变化

此前保存的页面只有赛道名称；这次页面新增了 Evaluation, Human Computation, and Resources 的完整说明。它明确邀请数据集、基准、测试集、模拟器和软件，按资源对 Web 社区的用途、质量、新颖性、文档和可获得性评估，并列出合成数据评价、基准污染和可复现研究。全文差异保存在 CFP_DIFF.txt，逐字证据见 CFP_EVIDENCE.json。

这支持继续走资源路线，不要求为了投稿强造新算法；但首页需说明具体 Web 相关科学问题的要求仍在。赛道接受这些主题，不等于本稿自动满足范围和新颖性。评审访问等行政事项仍按用户要求留待投稿，不当作本轮研究阻碍。

## 为什么做这项实验

固定版本的 Context is Key 交通下降任务先选择起点 s、时长 d 和比例 r，再把事件区间改为常数 r×v_s，并提供事件时间、比例和时长的文本提示。基准已有交通情景、提示消融和区域评分；这些不是 NET-V4 首创。

本次问题更窄：保持历史、事件提示和预测全部不变，只把事件目标从常数 r×v_s 换成逐时点 r×v_t，预测规则的比较是否会变？两种都是假设性构造，未宣布哪一种是真实交通机制、原作者的本意，或应当修复的错误。原论文模型排名未被测试。

协议在读取交通值之前固定。只取 TrafficFresh 指定提交的前 1 MiB，清单总文件长 304,418,602 字节，HTTP 206 和提交绑定通过。前缀含两个传感器的 7,736 条完整记录；按最小 ID、最早合格连续段选出 423339 的 1,834 小时。源数据选择在预测评分前完成。

执行原 task method 和 random-window helper 的未改动函数体，只用明确披露的局部数据加载器替代全传感器抽样。32 个固定种子全部成功。外部任务是 168 小时历史→24 小时未来，原 NET-V4 12→12 任务不变，二者不合并评分。

## 固定比较的结果

主要指标是每个情形等权的事件区间 MAE。预测规则仅使用历史和假设场景给出的时间、比例、时长。

|历史预测规则|原常数目标：锚点响应|原常数目标：逐点响应|逐点缩放目标：锚点响应|逐点缩放目标：逐点响应|
|---|---:|---:|---:|---:|
|最后值|0.826250|0.826250|0.542915|0.542915|
|前一日曲线|0.532188|0.489369|0.563509|0.356461|
|前七日平均曲线|0.469598|0.515620|0.345773|0.268499|

七日平均曲线的两种响应交换了优劣：原目标偏向锚点响应，替代目标偏向逐点响应。最后值的两种响应本来就相同；前一日曲线在主要指标下均为逐点响应更好，只有换成整段或按事件点汇总时才反转。不能把一次局部反转写成普遍排序结论。全部九个声明组合、两种目标、各实例评分和三种汇总口径完整保存。

144 个事件目标位置中有 108 个改变；事件外目标完全相同。27 个多小时区间在原操作下全部恒定，替代操作保留了变化。有 1 个情形的 4 个原操作目标高于原背景同一时点，这只是构造事实，不足以认定原任务违反其“通常交通”语义。

## 独立校验和实际用途

独立校验从原始 TSV 前缀重新选择源序列，逐项复现随机事件参数与文本提示；不调用参考 task methods、pandas 或主评分程序。1,536 个目标值完全一致，6,912 个保存预测值和 1,206 个评分值的最大误差均不超过 1.78e-15。NumPy 仅用于读取数组与保持原随机数及排序平局规则。

新附件还允许研究者对同一批输入提交自己的 32×24 点预测，并同时评分两种目标。用户预测入口已用打乱 seed 顺序的历史输入预测检查，能够按 ID 对齐并复现结果。它是资源使用接口，不另算一个新算法。
