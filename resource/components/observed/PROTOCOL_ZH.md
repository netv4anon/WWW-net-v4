# 同道路同周时刻的观测误差比较：执行前协议

2026-10-03。本实验回到原 NET-V4 的“事件标签是否代表困难样本”问题，用已保存的观测目标检查道路/周时刻选择及报告前差异。不重开已关闭的生成器诊断、恢复参数、选模或增强路线。其潜在用途是让基准使用者判断报告窗口的困难是否只是不同评价人口的关联，不能声称新匹配算法或真实事故因果效果。

## 固定对象与不看误差的配对

仅取既有主线任务二月273个报告，保留来源行和所关联的唯一主线站点。模型训练/选择仍只用一月；二月开发暴露如实保留。继续沿用完整主线目录、同freeway/方向、最近Abs PM≤0.5的任务定义；该关联不是实际受影响传感器真值。

令原预测切点c=floor(报告时刻/5min)+1，则c−1格含报告时刻。为避免把这一格误称“报告前”，前期预测切点固定c−13：输入[c−25,c−13)，目标[c−13,c−1)，其目标完全早于报告所在格。后期沿用原12→12输入[c−12,c)，目标[c,c+12)。源材料因此需要完整[c−25,c+12)的37格；两次预测在源点上有重用，不是假定独立重复。

每个报告的候选对照为同一站点、同一星期与同一5分钟切点的其余二月日期，即c±7/14/21天且在该月内。保留全部合格对照并等权平均，不挑最近/最好日期，不用预测误差或未来流量水平配对。对照完整37格内不得与任何已匹配报告区间相交；缺失/非正持续时间沿用24小时排除。病例扩展37格不得与除自身以外的已匹配报告相交。缺失、负值、月界、不完整与重叠均列出；没有任何合格对照的病例整体排除。无记录重叠不等于没有真实事件。

逐点绑定已保存二月发布张量或补充原字节块。所有配对与排除先写入冻结文件，再运行预测；模型不接收站点、报告、阶段、配对、来源索引或目标。原来的24格病例输入/目标必须与已存任务逐点相同。完整处理谱系和报告/传感器的独立时钟校准仍未得到证明。

## 固定预测器与统计量

复用 LastValue、HistoricalMean、LinearDrift、RidgeCenter及一月训练的三个STID种子，0新拟合。相同station/cut只预测一次，保持每个病例对其对照的既定权重。全部预测保存后评分；独立NumPy核验采用atol=0.0002、rtol=0.000001，对指标另作严格复算。

对每个病例i和模型m，分别计算报告前、报告后12步MAE，并减去该病例全部合格对照在同一时期的平均MAE：Δpre_i,m、Δpost_i,m。主要终点为G_i,m=Δpost_i,m−Δpre_i,m，称“误差差异的变化”。它不是实际事故效应，不以平行趋势或交换性已成立为前提。另报两项Δ及所有病例/对照原始MAE，避免用G隐藏原始困难。

主配置为三个STID种子的损失平均，并完整报告每个种子和四个基线。病例等权，对照在每病例内等权；不按模型或日历支持再挑子集。报病例日/站点支持、四个连续七日块、逐站点删除的敏感性、共享对照与来源点重用。周块和种子只用于描述稳定性，不当独立事故重复；不报告未被设计支持的因果或显著性结论。

## 执行前解释与停止规则

1. 若Δpost>0、Δpre>0而G≤0在三个STID种子及各有支持周块均成立，可以描述“本病例集合的较高预测误差在报告前已经存在，报告后未进一步增加”。这仍不识别事件开始时间或因果机制。
2. 若G>0在三个种子及各有支持周块均成立，可以描述“控制同道路周时刻并扣除报告前差异后，仍有一致方向的报告后额外误差关联”。不能恢复原稿的普遍更容易结论，也不能把发布报告等于物理冲击开始。
3. 其余情况记为异质或证据不足。无论哪种结果，都不自动成为WWW主创新；需说明它是否改变具体资源使用者的判断，以及近邻是否已有同样证据。禁止因符号不合预期增加新匹配变量、时点、模型、月份或挑选事件类别。
