# 核心 NET-V4 复用后果：执行前固定协议

2026-10-09。用户要求实质提高 WWW 稿件竞争力，故本轮恢复有明确问题的科学修订；10月9日此前的“只做投稿事务”安排不再作为本轮限制。旧稿、冻结包、全部旧结果与独立 v0.7 保留。

## 为什么值得做

当前稿最有力的复用后果来自外部发布物，未直接支撑核心 NET-V4 的资源增量。10月3日的原输入审计已经发现 mixed/working 有102条测试中心历史、74条完整中心序列与训练重复，而全九槽完整序列重复为0；只完成结构计数，未验证历史查表的预测后果。本研究直接把输入单位检查与原12→12资源的可用诊断联系起来。

这不是新发现重复数量，不是再次中心拷贝 Ridge 拟合，也不是扩展外部站点或寻找另一个恢复法则。新终点是原资源上固定历史查表的实际误差与命中/未命中后果。

## 固定问题与输入

- 问题：在原 mixed 12→12 划分上，重复的中心历史是否足以支持一个可利用的预测捷径？换为全九槽历史键时，这个判断是否改变？
- 两个快照都执行：packaged/generated 作为无中心精确复用的对照，working/mixed 为主要对象。旧划分、样本、目标、数值槽及量纲不变。
- 数据只取 submission_completion/netv4_review_candidate_v0_3/data/{packaged,working} 的 history、targets、splits、analysis_metadata，绑定SHA256。历史形状[N,12,9]，目标评分中心槽0。
- 结构已开发暴露；本轮不能声称独立盲测、时间泛化或物理源身份鉴定。

## 固定预测规则

1. 主输入键：12步中心槽0的原float32字节。预定范围对照键：完整12×9历史float32字节。只做这两种键，不采用近似匹配、额外中心ID、日期、事件标签或结果驱动的第三种键。
2. 仅从train构建历史→未来库。相同历史若有多条训练未来，预测为全部这些未来的float64算术平均；不按query未来选择训练行。
3. 主未命中回退：LastValue，重复最后一个中心历史值。命中替换为查表预测，未命中逐位保持回退预测。
4. 次要固定后果：对三个已保存的STID_NoCalendar种子，以其原测试预测作未命中回退。命中同样使用上述训练均值；不改权重、不重新训练，也不把它称为原STID自动利用了复用。
5. 各预测文件保存并作SHA256封印后才进行query未来评分。读取训练目标是查表规则的一部分；query目标不参与查找、匹配、参数或预测规则选择。

## 输出与科学终点

- 全部test查询保留。逐项呈现all、hit、miss、event/control、constant/varying target和训练未来unique/conflicting命中组；source字段仅用于事后描述，不参与推断。
- 每组报告查询数、点数、MAE、RMSE和损失变化；误差百分比以对应原回退MAE为分母。
- 同时输出每条命中query的train索引、完整中心未来是否也复现、训练未来冲突、数值常数与记录中心ID关系；这些后者是评分/解释诊断，不进入预测。
- 主命题获得支持须满足：mixed的中心键查表降低整体LastValue MAE，而且其varying-target命中组MAE也降低。任何不满足均照实报告；不按结果改门槛或追加匹配规则。
- 所有三个STID种子结果呈现，不能以其有利子集替代主终点。generated预期无命中，仍实际核对并报告。
- 主终点通过仅说明指定库与划分上的可利用性，不等于原模型成绩虚高、修复时间划分或已达到WWW接收门槛。

## 验证与停止

用另一条tuple键路径核对命中查询和训练集合；核对未命中预测与回退完全相同、总体损失变化完全来自命中，并核对旧102/74和0完整九槽复用计数。固定源/划分/预测指纹与全部结果随交付保留。

完成这两套快照、两种键与四个固定回退后停止本研究。失败或效应小也保留，不扩展近似距离、年份筛选、模型训练或额外快照。
