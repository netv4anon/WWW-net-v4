# 单一恢复方式替换：固定权重的响应可迁移性检查

2026-10-03，在生成替代序列、预测和评分前固定。本轮原任务仍为 NET-V4 的 12→12 中心预测；不改原快照或另一份 v0.7。旧 256 上下文及模型分数已经开发暴露，本检查不是独立盲测。

## 命题与使用者决定

当前最强例子为混合快照 STID：完整事件臂 MAE 比背景更低，但固定完整目标上的历史响应增益 A 在三个种子都为负。拟检验这一判断是否依赖旧恢复分支对背景波动的平滑，而非仅依赖事件脉冲及其消退。

使用者的具体决定是：能否把该例子解释成跨这两种恢复构造都存在的响应问题，还是只能给出旧生成器条件下的结论。若负响应只在原公式下出现，必须收紧解释，不追加参数搜索来恢复预期符号。此检查本身不是新算法、普遍事件规律或 WWW 创新成立的证据。

## 固定材料与唯一改动

复用全部 256 上下文、背景 profile、旧 seed=20260909、随机数顺序及事件参数。首先完整重放 B/P/R/F，与已有四臂 float32 数组逐位相同。替代构造使用同一次抽样的未裁剪脉冲值，避免将裁剪差异混入恢复方式比较。

令背景为 v，事件结束位置为 e，未裁剪脉冲最后一点为 a，q(t)=exp(-(t-e)/tau)，tau=max(2,response_seconds/900)。旧恢复为：

`F_old(t) = v(t) + (a - v(t)) q(t)`，t≥e。

唯一替代为：

`F_residual(t) = v(t) + (a - v(e-1)) q(t)`，t≥e。

恢复前使用完全相同的脉冲；之后都采用旧下限 3 及上限 1.3*max(v) 的裁剪。未裁剪时 `F_residual(t)-F_old(t) = (v(t)-v(e-1))*q(t)`。背景恒定时二者一致；脉冲为零时替代构造退化为原背景，而旧恢复仍可能改变背景。该替代用于分离已知代码机制，不宣称是经过实测校准的交通恢复定律。禁止扫描 tau、严重度、噪声或换上下文。

数据上限：256 条新的完整 24 步构造序列；0 新观测、0 新 profile、0 新随机上下文。旧 B/P/R/F 仅重放，不计新增。替代无脉冲臂恒等于 B，验证其恒等性，不再制造重复发布行。

## 模型、时序和指标

复用三个确定性预测器、两份快照的 RidgeCenter 和六个 STID 种子，共 11 个不同配置。仅预测新的 F_residual 历史，11 组输出全部保存并固定后才读取替代未来评分。使用既有中心推理路径；不构造空间邻居，不拟合或选择模型，0 新训练。背景与旧完整臂预测复用已存输出。

主终点为全部 256×12 点的 MAE 及 B→F 的 D/T/A 分解：

`D=L_FF-L_BB`，`T=L_BF-L_BB`，`A=L_BF-L_FF`。

全部 11 配置和两个恢复版本均报告，不依据结果选择模型。附加报告历史完成、跨切点、未来开始、48 个旧 test-origin 上下文，以及原 pulse/post-pulse 掩码。这些分层用于解释，不能作为独立城市、源隔离测试或独立样本的显著性证据。保留逐上下文损失及符号转换。

## 预定判读和停止

1. 混合 STID 三个种子的 A 在替代恢复下都仍<0：原负响应现象在这一个替代构造下保留；仍不推广到其他生成器或实测事件。
2. 至少一个变为≥0：原“三种子同向”的现象依赖恢复方式；以全部具体值说明，不能只挑均值或有利种子。
3. 原 STID 的完整臂准确率优势是否保留单独报告，A 不作为模型总排名依据。
4. 技术前提包括旧四臂精确重放、同脉冲与相同参数、零脉冲恒等、恒定背景等价、预测只用历史、独立 NumPy 推理及逐点损失核验。若旧重放失败停止，不改 seed 或替换原数据。

完成此一次检查即收口。普通固定目标消融也能计算 A；不以该公式宣称方法优先权。本轮近邻代码核查与本实验只决定下一阶段是否值得研究构造方式之间的迁移，不自动满足资源独特性和 Web 科学贡献要求。
