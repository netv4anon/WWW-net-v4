# 已有方法对照与贡献边界

2026-10-03。这是基于已读文献与现有证据的投稿判断，不是穷尽检索，也不是接收概率估计。原任务为NET-V4的12→12交通预测；本轮没有换成文字预测、通用LLM评价或另一个数据集。

CheckList已读摘要、引言、§2及其测试类型；CiK已读摘要、§§2–5相关内容、数据说明及附录C.10。CiK的正式出版记录已从PMLR核实，PMLR267:66887–66944。它的arXiv版本为2410.18959v4。本地保存全文和公开记录；没有执行CiK代码或重跑其模型，不能宣称独立复现其结果。附录C.10里具体模型名存在前后不一致，因此这里只采纳“整体评分与逐任务表现可不同”的一般讨论，不引用其特定模型例子。

## NET-V4实际增加了什么

NET-V4当前提供同一随机背景下的B/P/R/F历史和目标，并计算完整4×4交叉损失。固定F目标比较两种历史时，`A=L_BF-L_FF`表示对该目标的历史响应收益；`D=T-A`再把同臂误差差值拆成一条指定路径。CiK的有/无文字消融固定目标、改变文字输入；本稿同时保存变化前后的数值历史和目标。这是本资源的具体使用方式不同，**不是证明通用诊断方法优先权**。

该能力的实际案例已经存在：混合训练快照的STID全臂误差更低，但固定目标的历史响应收益为负。使用者由此应撤回“误差降低证明模型识别了事件”的解释。STID仍是这些配置中全臂误差最低者，不能因为A为负宣布它整体较差，更不能按A选出实用上最好的交通模型。相同历史的95个上下文是构造设计给出的信息限制，不是新发现的现实预测极限。

`D=T-A`是路径相关的损失恒等式。改变路径可得到其他分解。CheckList式测试可以表达这里的输入响应要求，常规消融也可以计算固定目标差值；当前没有证明接口提供了这些方法原则上缺少的能力。对NET-V4自身构造的诊断目前也不能推广成真实事件影响的识别方法。

## 投稿判断与投入决定

1. **保留**：原数据谱系、具体评分支持范围、配对构造诊断、完整预测与可执行工具。它们形成可信的资源分析材料。
2. **降为案例**：TraffiDent关联选择与目标资格检查，用于展示评价依赖任务定义，不再承担主要算法创新。
3. **不成立**：仅凭以上内容，宣布新的通用反事实方法、事故响应算法、Web数据融合理论，或WWW高概率长文。
4. **停止自动扩张**：不再为同一D/T/A现象追加月份、种子、弱基线、界面或压缩包来提升自评分。软件本轮闭环后，类似工作不构成新的科学进展。

下一项若仍要争取WWW研究长文，必须先写出一个目前材料之外、且可证伪的独立资源用途：明确谁利用它做什么决策，为什么已有行为测试/消融不能充分支持该决策，新增证据如何改变真实的评价结论。这是本项目的投入准入判断，不是声称WWW官方强制新算法、第二数据集或用户研究。若只能重复现有构造恒等式和边界警告，应停止把原稿继续包装成WWW高概率长文，转为收敛的交通评价/资源稿并核对具体场所。换场所本身也不补足贡献。

本轮的结论是**“原材料有保留价值，但独立WWW贡献尚未成立”**，不是“数据集无价值”，也不是“接口完成所以可投”。先前约60/100的主观内容评分没有因本轮工程工作而上调。另一份交通响应资源v0.7不参与本判断。
