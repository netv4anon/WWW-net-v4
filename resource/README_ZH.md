# NET-V4 当前资源入口

完整命令和输出解释见 `READER_GUIDE.md`；当前正文与技术补充位于上一级 `manuscript`。组件内的旧稿和审查记录是历史证据，不代表当前稿件。

原两快照、256中心配对任务与新 NET-V4-MV 分别标识。原 12→12 任务保留；MV 提供 11,424 个条件构造场景、68,544 条六视图输入，支持 `[N,12,9]` 历史到 `[N,12]` 中心点预测。102 份完整数值周轮廓与固定配置能够再生成新数组，但没有恢复原快照的历史原始来源。九槽包括中心、中心副本和七个按轮廓相似度选择的序列；不是实测道路邻接。

统一入口有九个可运行重放组件、六个自有预测评分组件。先执行 `python -B resource.py list` 与 `python -B resource.py show 组件名`。重放新任务：

```text
python -B resource.py verify
python -B resource.py replay netv4_mv --out ../mv_replay
python -B resource.py score netv4_mv --predictions components/netv4_mv/predictions/working__RidgeLocal9.npz --out ../mv_reader_scores
```

输出目录应位于资源目录外，且此前不存在。中心任务通过 `netv4` 与 `netv4_checks` 评分同一份 1,024 条预测；后者也重放原快照查表与指定目标线段检查。完整联合输入使用 `netv4_mv`，全部 68,544 个 ID 必须各出现一次；读者接入示例见英文指南。

新任务中，联合 Ridge 总响应有帮助，但中心历史固定后增加其他序列的事件历史会小幅增加误差。单独标识的 Graph WaveNet 用途研究在全部六个主检查点和两种目标下保留同一分歧，三种子损失均值的条件误差增加为 2.55%–3.54%，有帮助的轮廓组也保留。STID 与 Graph WaveNet 均呈现总体响应不利、跨起点组有利。不要用总体响应替代分组判断。Graph WaveNet 原 Mixed 测试准确率差于 STID，不能称为普遍性能提升。原快照查表整体改善仅 0.12%，全部命中是控制样本；外部发布物的 11.79% 改善是另一总体。

新增神经预测仍通过既有 `score netv4_mv` 评分；原 `replay netv4_mv` 只重放继承的 13 个配置。新组件说明见 `components/netv4_gwn/README.md`，包含六主配置、被替代的完整技术拟合和中断记录，以及不拟合的训练暂存重建命令。

外部来源审计、站点查表与支持排除需要精确绑定的上游文件，未随包分发。真实观测参照只承担描述比较；CiK 两站实验是另一个时长和构造。Qwen 输出有效性门槛失败、选择/增强/风险校准未形成稳定收益等既有不利结果仍在包内。

数值完整性、再生成与直接损失核对分别有记录。数据规模、程序能运行或自评分均不能替代新颖性与社区用途，也不构成录用保证。当前包仅在本地；实际访问、来源条款和投稿声明按既有约定留至投稿阶段。
