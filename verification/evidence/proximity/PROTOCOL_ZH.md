# 合成诊断输入可比性：单次限定检查

日期：2026-10-11。用户询问如何解决合成合理性质疑。本项检验MV诊断是否只在远离原训练输入的视图上呈现响应分歧；不改变数据构造、模型、训练、预测或原论文的完整结果。既有结果已在开发中公开，故本项是事后固定规则的解释检查，不称独立预注册确认。

## 单一问题

在一个只依赖历史输入的预定接近度规则下，B、C、F三个视图同时接近原训练历史时，跨预测起点组的“总响应有利、条件其他序列响应有害”是否仍成立？三个视图均纳入是为了让总响应的B/F比较和条件响应的C/F比较共享参照要求。

## 数据和度量

1. 两训练版本分别使用原train索引里的全部12×9历史，保持模型实际数值槽顺序、中心副本及12→12任务。使用验证历史确定阈值。测试历史与所有预测误差均不用于规则选择。
2. 每个历史展平为108个值，使用该版本原训练历史的全局均值和标准差缩放。接近度定义为它与训练历史的最近邻标准化均方根距离。只采用这一种表示和距离，不进行特征、槽权重或距离搜索。
3. 阈值为原validation历史到train最近邻距离的95%分位数，使用NumPy线性分位数定义。MV场景只有在B、C、F距离均不超过该阈值时才纳入。阈值不是“同分布”证明或物理真实性标准。
4. 全部11,424场景计算输入距离，分四种既定时序报告覆盖。主要判断仍对应2,856个cutoff_spanning场景。所有102个profile及其依赖保留说明。
5. 覆盖充分的预定描述门槛：主要组纳入至少50%场景，且至少80%的102个profile各保留不少于14/28场景。此门槛仅决定可否把结果称为覆盖广泛的适用边界证据，不是显著性、独立样本量或录用门槛。

## 评分和结果分支

输入规则及选择掩码保存后，读取已有Graph WaveNet六个主检查点的预测；同时报告两训练版本、三种子、两目标、全体/纳入/排除组。报告A=L_BF-L_FF和A_other=L_CF-L_FF、各损失、三种子损失均值、profile条件均值及正负profile计数。完整原分数先与冻结CSV核对。样本不视为独立事故，不生成置信区间或显著性结论。

- 两版本覆盖均过门槛且六主检查点在两目标下纳入组仍A>0、A_other<0：可称分歧在本规则下接近训练参照的输入上仍存在。仍不证明同分布、真实事故机制或道路传播。
